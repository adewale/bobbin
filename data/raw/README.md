# Raw source fixtures

These HTML files are cached exports of Alex Komoroske's published
"Bits and Bobs" Google Docs (the doc IDs in the filenames match the
trusted source registry in `src/data/source-registry.ts`). They are
checked in so the node-runtime corpus tests and the local fixture
pipeline can run hermetically, without fetching from Google Docs.

The written content belongs to its author and is **not** covered by this
repository's MIT licence, which applies to the code only. The files are
retained here as test fixtures for a public archive of publicly published
material; if the author requests removal, delete them and point the
corpus tests at freshly fetched copies instead.
